# Lab notebook: workload-level MTP acceptance

Date: 2026-09-13 UTC
Track: workload-aware MTP tuning ([issue #1](https://github.com/moriyasujapan/qwen38-flash-next-cmp170hx/issues/1))
Configuration: `NEXTN steps=1`, `draft_tokens=2`, FP16 GDN state

## Method

`bench/mtp_acceptance.py` sends one streaming request per workload and records Prometheus
counter deltas around the request. The acceptance length is calculated from
`generation_tokens_total / spec_verify_calls_total`; the last `spec_accept_length` gauge is
also retained for diagnostics. A request is marked contaminated if the streaming request
counter increases by anything other than one. Contexts are synthetic and are only used to
exercise the prefill path, not as a quality claim.

Command:

```bash
python3 bench/mtp_acceptance.py \
  --config-label nextn-s1-d2-fp16 \
  --contexts 0 8192 --repeats 1 --max-tokens 256 \
  --output results/mtp-nextn-s1-d2-fp16-20260913.jsonl
```

## Result

All 12 samples were uncontaminated. The aggregate decode median was 66.11 tok/s and the
mean counter-derived acceptance length was 1.827 tokens (draft-token ceiling: 2).

| workload | accept length @ context 0 | accept length @ context 8192 | decode range (tok/s) |
|---|---:|---:|---:|
| code_python | 1.829 | 1.896 | 65.08–66.43 |
| code_patch | 1.910 | 1.954 | 66.49–69.17 |
| japanese_explanation | 1.741 | 1.718 | 59.19–63.03 |
| reasoning_logic | 1.816 | 1.778 | 60.13–65.79 |
| verbatim_context | 1.293 | 2.000 | 46.90–69.32 |
| structured_json | 2.000 | 1.984 | 67.01–72.01 |

The 8K-context TTFT was approximately 7.8 s in this isolated run, so it is not comparable
to the warm-prefix baseline. `structured_json` is the strongest candidate for a larger draft
window; `verbatim_context` is unstable across the two context conditions and needs repeats.
This run is a measurement baseline, not an automatic runtime change.

## Selection and rollback

`scripts/select_mtp_config.py` currently recommends the only tested configuration:

```text
SPEC_STEPS=1 SPEC_DRAFT=2
```

The selector is deliberately offline. A future auto-selector must compare repeated workload
matrices, impose a TTFT regression limit, and fall back to the frozen launcher values. No
production flags were changed by this experiment.
